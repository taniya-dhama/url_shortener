## Overview
The URL Shortener is a web-based application that converts long and complex URLs into short, simple, and easy-to-share links. It allows users to enter a long URL and generate a unique shortened URL that can be used instead of the original link. The application stores the original URL along with its corresponding short code in a database, making it possible to retrieve the original link whenever the shortened URL is accessed. When a user opens the short URL, the application automatically redirects them to the original webpage. This project demonstrates practical concepts such as URL routing, database management, unique code generation, HTTP requests, and URL redirection. It provides a simple and user-friendly way to manage long URLs and can be further enhanced with features such as custom short links, link expiration, click tracking, QR code generation, and user authentication.


## How It Works
User enters a long URL.
The application generates a unique short code.
The original URL and short code are stored in the database.
The generated short URL is displayed to the user.
When the short URL is opened, the application finds the original URL.
The user is redirected to the original website.
